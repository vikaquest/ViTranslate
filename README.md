# ViTranslate

Бесплатный локальный переводчик и помощник ввода для Windows 11 (x64).

**[Скачать portable-версию 1.5.0](https://github.com/vikaquest/ViTranslate/releases/tag/v1.5.0)** · [Скачать с Яндекс Диска](https://disk.yandex.kz/d/3QyB-h0e3Vc8bA)

## Возможности

- Русский ↔ английский перевод на компьютере, без отправки текста на сервер.
- Подсказки «Дополнить», «Исправить» и «Предложить», выбор и замена через Tab или назначенную горячую клавишу.
- Перевод выделенного текста, в том числе сообщений Telegram. Нажатие на результат копирует перевод.
- Обычный и компактный режимы. В компактном режиме можно показывать результаты в правом нижнем углу или рядом с переводимым текстом, включая выделение вне поля ввода.
- Рядом с текстом окно старается появиться справа сверху. Если места не хватает, оно сдвигается внутрь экрана или располагается снизу.
- Отдельные настройки подсказок, переводов, количества вариантов и видимости значка словарика для каждого режима. Максимальная ширина компактного окна настраивается и включает значки.
- Блокировка обычного Tab в распознанном поле ввода: пока подсказка не готова, фокус остаётся в поле. Готовая подсказка выбирается как обычно. Сочетания с модификаторами и Tab вне распознанного поля не блокируются.
- Переключение раскладки одиночным нажатием правого Alt. Сочетания AltGr для ввода символов продолжают работать.
- Сохранение собственных стилей и семь обновлённых готовых вариантов оформления.
- Настройка цветов, непрозрачности, размера текста, питомца, скруглений, рамок и центральной линии. Для компактного вида отображаются только относящиеся к нему параметры дизайна.
- Стандартное оформление окна настроек можно сохранить независимо от выбранного стиля приложения.
- Персональный словарик для изучения слов: пары «русский — английский», скрытый английский перевод и раскрытие по одной букве. ПКМ по переводу добавляет слово, ЛКМ по скрытому переводу открывает букву, ПКМ по нему удаляет пару. Длинные записи переносятся на новую строку.
- Ручное добавление и очистка словарика, словарь подсказок и сокращения для быстрого ввода текста.
- Распознавание браузерных редакторов, включая поле комментариев YouTube.
- Настраиваемые клавиши показа / скрытия и выбора варианта, включая Mouse 4 / Mouse 5. По умолчанию — Alt + Q и Tab.
- Автозагрузка вместе с Windows через галочку в общих настройках. После перемещения portable-папки включите её заново из нового расположения.
- Подсказка при запуске: после закрытия крестиком больше не появляется.
- Справка, меню в трее, уведомление о новых версиях и обновление из приложения.
- Диагностика в отдельном окне поверх остальных: отчёт для копирования с текстом, выделением, сведениями о поле и странице. Парольные поля исключены; текст не записывается в журнал на диске.

## Запуск

1. Скачайте **ViTranslate-portable-win-x64-1.5.0.zip** из [Releases](https://github.com/vikaquest/ViTranslate/releases/latest) или с [Яндекс Диска](https://disk.yandex.kz/d/3QyB-h0e3Vc8bA).
2. Полностью распакуйте архив в отдельную папку, доступную для записи.
3. Запустите **ViTranslate.exe** из корня распакованной папки.

Python, .NET и модели перевода включены в комплект. Установка не требуется. Не перемещайте EXE отдельно от остальных папок.

При первом запуске включён **компактный режим**. Начните вводить текст в поле или выделите текст для перевода. **Alt + Q** включает и скрывает приложение; в полноэкранных приложениях горячая клавиша по умолчанию отключена.

Правый клик по значку в трее открывает переключение режима, «Показать» / «Скрыть», справку, настройки и выход. Левый клик в компактном режиме открывает меню со статусом приложения и быстрыми командами. Крестик обычного окна сворачивает приложение в трей; пункт «Закрыть» в меню полностью завершает работу.

Добавление слов горячей клавишей Shift + Tab больше не используется. Для добавления в словарик нажмите правой кнопкой мыши на слово перевода.

## Настройки по умолчанию

«Блокировать Tab в поле ввода» и «Отключать горячую клавишу в полном экране» включены. Переключение раскладки правым Alt, диагностика и автозагрузка выключены. «Стиль по умолчанию для настроек» включён.

| Параметр | Обычный режим | Компактный режим |
|---|---|---|
| «Дополнить» | 5 вариантов | 3 варианта |
| «Исправить» | 2 варианта | 2 варианта |
| «Предложить» | 5 вариантов | 2 варианта |
| Перевод русского текста | 3 варианта | 1 вариант |
| Блоки подсказок | С новой строки, с заголовками | С новой строки, без заголовков |
| Значок словарика | Показан | Скрыт |
| Максимальная ширина | — | 250 px, включая значки |
| Расположение | — | Правый нижний угол |

Подсказка запуска показывается до первого закрытия крестиком. Признак закрытия сохраняется в **userdata/preferences.json**.

Во вкладке «Дизайн» можно сохранить стиль, выбрать готовый и открыть палитру цвета. Кнопка «Применить» в палитре обновляет предпросмотр без закрытия палитры. В стиле «По умолчанию» толщина рамки подсказок и полей — **0 px**.

Настройки, собственные стили, персональные слова и сокращения хранятся в папке **userdata** и сохраняются при обновлении. Новые значения по умолчанию используются для новой установки; существующие настройки пользователя не сбрасываются.

## Работа без интернета

Перевод и подсказки работают локально. Набранный и выделенный текст не отправляется на сервер для перевода.

Интернет нужен для проверки и скачивания обновлений и для окна поддержки. Реквизиты и социальные ссылки загружаются по сети при открытии поддержки; на диск они не сохраняются.

## Обновления

Приложение проверяет новые версии при запуске и каждые 6 часов. Скачивание и установка начинаются после нажатия кнопки обновления. Можно перейти сразу на последнюю версию, без последовательной установки промежуточных выпусков. Настройки, стили и словарики сохраняются.

С версии 1.4.4 поддерживается резервное скачивание обновлений с Яндекс Диска, без входа в аккаунт. Можно также [скачать portable 1.5.0 вручную](https://disk.yandex.kz/d/3QyB-h0e3Vc8bA). Пакет обновления предназначен для встроенного обновлятора; для первого запуска нужен полный portable-архив.

## Обратная связь

Если обнаружили ошибку, создайте [Issue](https://github.com/vikaquest/ViTranslate/issues) с шагами воспроизведения. Диагностику можно включить в настройках и скопировать отчёт из появившегося окна. Отчёт содержит текст поля; перед отправкой можно убрать личные сведения. Также доступен ZIP с техническим журналом без набранного текста. Автоматическая отправка отчётов не выполняется.

В этом репозитории размещаются описание и готовые сборки. Исходники приложения не опубликованы.
