# ViTranslate

Бесплатный локальный переводчик и помощник ввода для Windows 11 (x64).

**[Скачать portable-версию 1.0.0](https://github.com/vikaquest/ViTranslate/releases/tag/v1.0.0)** · **[Зеркало проекта на GitFlic](https://gitflic.ru/project/vikaquest/vitranslate)**

## Возможности

- Русский ↔ английский перевод с локальными моделями.
- Подсказки английских слов, исправления и выбор вариантов через Tab.
- Перевод выделенного текста и текста возле каретки в поле ввода.
- Компактное окно, трей, режим поверх окон и режим фокуса ввода.
- Настраиваемая горячая клавиша, цвета, размер текста и оформление.
- Уведомление о новых версиях и обновление из приложения.
- Диагностика без сохранения набранного текста по умолчанию.

## Запуск

1. Скачайте **ViTranslate-portable-win-x64-1.0.0.zip** из раздела Releases.
2. Полностью распакуйте архив в отдельную папку.
3. Запустите **ViTranslate.exe** в корне этой папки.

Установка Python или .NET не требуется. Модели уже включены в архив; первый запуск может занять немного времени. Не перемещайте EXE отдельно от остальных папок.

По умолчанию **Alt + Q** показывает или скрывает окно. Режим работы выбирается через меню; горячую клавишу можно изменить в настройках.

## Приватность и работа без интернета

Перевод выполняется на компьютере. Набранный текст не отправляется на сервер для перевода.

Интернет используется для необязательных обновлений приложения и данных поддержки. Реквизиты и социальные ссылки загружаются при открытии окна поддержки из [публичной конфигурации](https://github.com/vikaquest/vitranslate-config); последние корректные данные сохраняются локально. При недоступности GitHub приложение использует GitFlic.
