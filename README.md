# ViTranslate

Бесплатный локальный переводчик и помощник ввода для Windows 11 (x64).

**[Скачать portable-версию 1.4.4](https://github.com/vikaquest/ViTranslate/releases/tag/v1.4.4)**

## Возможности

- Русский ↔ английский перевод на компьютере, без отправки текста на сервер.
- Подсказки «Дополнить», «Исправить» и «Предложить», выбор и замена через Tab.
- Перевод выделенного текста, в том числе сообщений Telegram. Нажатие на результат копирует перевод с уведомлением «Скопировано».
- Обычный и компактный режимы. В компактном режиме отображаются только результаты возле нижнего правого угла экрана при вводе или выделении текста.
- Отдельные настройки подсказок, переводов и количества вариантов для каждого режима.
- Сохранение собственных стилей и 7 готовых вариантов оформления.
- Настройка цветов, непрозрачности, размера текста, питомца, скруглений, рамок и центральной линии. Можно сохранить стандартное оформление окна настроек независимо от выбранного стиля приложения.
- Персональный словарик для изучения слов: пары «русский — английский», скрытый английский перевод и раскрытие по одной букве. Shift + Tab вставляет перевод русского слова и сохраняет пару; ПКМ по переводу добавляет слово.
- Словарь подсказок и сокращения для быстрого ввода текста.
- Распознавание браузерных редакторов, включая поле комментариев YouTube.
- Горячая клавиша или Mouse 4 / Mouse 5; возможность отключать её действие в полноэкранных приложениях.
- Меню в трее, уведомление о новых версиях и обновление из приложения.
- Диагностика в отдельном окне поверх остальных: отчёт для копирования с текстом, выделением, сведениями о поле и странице. Парольные поля исключены; текст не записывается в журнал на диске.

## Запуск

1. Скачайте **ViTranslate-portable-win-x64-1.4.4.zip** из [Releases](https://github.com/vikaquest/ViTranslate/releases/latest).
2. Полностью распакуйте архив в отдельную папку, доступную для записи.
3. Запустите **ViTranslate.exe** из корня распакованной папки.

Python, .NET и модели перевода включены в комплект. Установка не требуется. Не перемещайте EXE отдельно от остальных папок.

При первом запуске включён **компактный режим**. Начните вводить текст в поле или выделите текст для перевода. **Alt + Q** включает и скрывает приложение; в полноэкранных приложениях горячая клавиша по умолчанию отключена.

Правый клик по значку в трее открывает переключение режима, «Показать» / «Скрыть», настройки и выход. Левый клик в компактном режиме открывает меню со статусом приложения, словариком, переключением режима и видимости, настройками и выходом.

## Настройки по умолчанию

Все подсказки и оба перевода английского текста включены. Диагностика выключена.

| Параметр | Обычный режим | Компактный режим |
|---|---|---|
| «Дополнить» | 5 вариантов | 2 варианта |
| «Исправить» | 2 варианта | 2 варианта |
| «Предложить» | 5 вариантов | 2 варианта |
| Перевод русского текста | 3 варианта | 2 варианта |
| Блоки подсказок | С новой строки, с заголовками | В строку, без заголовков |

Во вкладке «Дизайн» можно сохранить стиль, выбрать готовый, изменить рамки и открыть палитру цвета. Кнопка «Применить» в палитре обновляет предпросмотр без закрытия палитры. Толщина рамки подсказок и полей по умолчанию — **0 px**.

Настройки, собственные стили, персональные слова и сокращения хранятся в папке **userdata** и сохраняются при обновлении. Новые значения по умолчанию используются для новой установки; существующие настройки пользователя не сбрасываются.

## Работа без интернета

Перевод и подсказки работают локально. Набранный и выделенный текст не отправляется на сервер для перевода.

Интернет нужен для проверки и скачивания обновлений и для окна поддержки. Реквизиты и социальные ссылки загружаются по сети при каждом открытии поддержки; на диск они не сохраняются. Если загрузить данные не удалось, окно остаётся в состоянии загрузки и повторяет попытку до закрытия.

## Обновления

Приложение проверяет новые версии при запуске и каждые 6 часов. Установка начинается после нажатия «Обновить». Настройки, стили и словарики сохраняются.

С версии 1.4.4 поддерживается резервное скачивание обновлений с Яндекс Диска, без входа в аккаунт. Можно также [скачать portable 1.4.4 вручную](https://disk.yandex.kz/d/Jv5AslhCayic7A). Пакет обновления предназначен для встроенного обновлятора; для первого запуска нужен полный portable-архив.

## Обратная связь

Если обнаружили ошибку, создайте [Issue](https://github.com/vikaquest/ViTranslate/issues) с шагами воспроизведения. Диагностику можно включить в настройках, скопировать отчёт из появившегося окна и приложить его к обращению. Отчёт содержит текст поля; перед отправкой можно убрать личные сведения. Также доступен ZIP с техническим журналом без набранного текста. Автоматическая отправка отчётов не выполняется.

В этом репозитории размещаются описание и готовые сборки. Исходники приложения не опубликованы.
