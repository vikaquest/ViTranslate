# ViTranslate

Бесплатный локальный переводчик и помощник ввода для Windows 11.

- Русский ↔ английский перевод с локальными моделями.
- Подсказки английских слов, исправления и выбор через Tab.
- Компактное окно поверх приложений, трей, горячая клавиша и настройки оформления.
- Portable-версия без установки.

Первый публичный релиз готовится. Его окно поддержки будет получать текст, ссылку и QR-код из [публичной конфигурации](https://github.com/vikaquest/vitranslate-config). Изменение реквизитов не потребует выпуска новой версии приложения.

Перевод выполняется на компьютере. Набранный текст не передаётся для перевода или загрузки конфигурации. Интернет используется только для необязательного обновления данных поддержки; последние корректные данные сохраняются локально.

Релизы будут публиковаться в разделе [Releases](https://github.com/vikaquest/ViTranslate/releases). В этом репозитории размещаются описание, отчёты об ошибках и готовые сборки; исходники приложения пока не опубликованы.

Если обнаружили ошибку, создайте Issue с шагами воспроизведения. Диагностику можно включить в настройках и вручную приложить её ZIP-отчёт: набранный текст в журнал не сохраняется.
