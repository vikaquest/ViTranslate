# ViTranslate

Локальный переводчик и подсказки ввода для Windows x64. Переводит текст во время набора, выделенный текст и области экрана. После скачивания моделей перевод работает без интернета.

**Версия 2.0.0** — [скачать защищённый portable](https://github.com/vikaquest/ViTranslate/releases/download/v2.0.0/ViTranslate-portable-win-x64-2.0.0.zip) · [описание релиза](https://github.com/vikaquest/ViTranslate/releases/tag/v2.0.0)

## Что нового в 2.0.0

- **Gemma 4 E2B и E4B**: выбор модели в трее, отдельное скачивание в настройках, необязательное ускорение на GPU.
- **Языки перевода Gemma**: с русского на английский, немецкий, французский, итальянский, испанский, португальский, китайский, японский и корейский. Язык меняется в настройках или в карточке, открытой кнопкой вопроса.
- **Alt + Q: Windows OCR или Gemma**. В режиме Gemma модель читает выделенное изображение напрямую, в том числе китайский текст. Для этого отдельно скачивается необязательный компонент mmproj.
- **Три режима запроса к Gemma**: изменить перевод, объяснить текст и задать постоянный контекст и стиль. Добавлена поддержка Markdown; оригинал, перевод и ответ доступны в одной прокручиваемой карточке.
- **Подсказки в одну строку**: горизонтальная прокрутка без полосы, плавное сопровождение выбранного слова при переборе Tab. Обычные отдельные подсказки тоже доступны.
- **Обучение на выбранных словах**: собственное написание можно выбрать и сохранить в личной статистике; знакомые слова поднимаются в подсказках.
- **Разделены действия Tab и Ctrl + Tab**: перебор подсказок и вставка перевода. Сочетания можно переназначить и поменять местами.
- **Единая загрузка последней выбранной модели** при запуске и показе приложения. После необязательной выгрузки по таймеру модель снова загружается при вводе, выделении текста и переводе области. Статус загрузки виден в интерфейсе.
- **Обновлён результат перевода области**: одна панель, минимальный шрифт 14 px, расширение области и прокрутка. Клик снаружи закрывает результат.
- **Исправлены** скрытие подсказок при Win + Shift + S, прокрутка между блоками, область нажатия кнопок, рамки и скругления по настройкам.

## Установка и обновление

1. Скачайте ZIP из [GitHub Releases](https://github.com/vikaquest/ViTranslate/releases/latest).
2. Распакуйте архив целиком в доступную для записи папку.
3. Запустите **ViTranslate.exe** из корня папки. Отдельная установка .NET и Python не требуется.
4. Выберите модель через значок приложения в трее. Argos уже включён; Gemma при необходимости скачивается в **Настройки → Опции → Модели перевода**.

В архив включены Argos RU ↔ EN, словари и необходимая среда выполнения. **Весов Gemma E2B, E4B и файлов mmproj в архиве нет.**

Настройки, личные словарики и стили хранятся в `userdata`. Обновление из приложения сохраняет пользовательские данные и скачанные дополнительные модели. Не удаляйте `userdata` при ручном переносе.

## Модели

| Модель | Назначение | Отдельное скачивание |
| --- | --- | --- |
| Argos | Русский ↔ английский, обычный перевод | Не требуется, включён в portable |
| Gemma 4 E2B | Перевод, переформулировки, объяснения и контекст | Около 3,35 ГБ весов и среда запуска |
| Gemma 4 E4B | Более крупная модель для тех же задач | Около 5,15 ГБ весов и среда запуска |
| mmproj для E2B | Чтение изображений выбранной E2B в Alt + Q | Около 987 МБ, необязательно |
| mmproj для E4B | Чтение изображений выбранной E4B в Alt + Q | Около 992 МБ, необязательно |

Для перевода при вводе, выделении текста и через Windows OCR **mmproj не нужен**. Он скачивается отдельно для соответствующей модели и автоматически вместе с Gemma не устанавливается. Размеры в таблице указаны в десятичных ГБ/МБ; в интерфейсе они могут отображаться в двоичных единицах.

По умолчанию Gemma работает на CPU. В настройках можно включить GPU; если ускоренный запуск не удаётся, используется CPU. Более крупная модель требует больше памяти и не гарантирует правильный перевод: имена, игры, сленг и неоднозначные выражения полезно уточнять в контексте.

## Управление

| Действие | По умолчанию |
| --- | --- |
| Показать / скрыть приложение и загрузить / выгрузить модель | Shift + Q |
| Выбрать следующую словарную подсказку | Tab |
| Вставить перевод / перевести выделенный текст | Ctrl + Tab |
| Перевести выделенную область экрана | Alt + Q |
| Изменить перевод Gemma | Средняя кнопка мыши по переводу |

Горячие клавиши настраиваются в «Опции». Tab перебирает подсказки по кругу; действия подсказок и перевода можно поменять местами. Работа с чужим полем ввода зависит от его поддержки Windows UI Automation и вставки текста. Для перевода выделения редактор должен поддерживать копирование и вставку.

ЛКМ и ПКМ по значку в трее открывают одно меню; повторное нажатие закрывает его. Там доступны выбор модели, словарик, справка, настройки и проверка обновлений.

## Запросы к Gemma

Нажмите вопросик рядом с переводом: появятся оригинал и поле запроса. Слева переключаются три режима:

- **Изменить перевод** — например: «Переведи неформально» или «Замени leap другим словом». Запрос относится к исходному тексту.
- **Объяснить** — например: «Что означает couple? Составь с этим словом предложение на английском». Ответ выводится отдельно от самого перевода.
- **Контекст и стиль** — постоянные пожелания: «Общение с друзьями в игровом чате. Titan — персонаж игры, а не металл. Используй разговорный английский без эмодзи».

Контекст сохраняется после закрытия поля; точка в правом верхнем углу карточки показывает, что он задан. Черновики двух разовых режимов очищаются при закрытии кликом снаружи. Встроенная кнопка вопроса в поле кратко объясняет выбранный режим.

Обычная карточка перевода остаётся компактной: заголовок и выбор языка появляются после открытия вопросика. Смена контекста или языка не перезагружает модель.

## Перевод области экрана

Нажмите **Alt + Q** и выделите область. Выбор распознавания находится в **Настройки → Опции → Модели перевода → Распознавание области экрана**.

- **Windows OCR** — распознаёт русский и английский; нужен соответствующий OCR-компонент Windows. После распознавания текст переводит выбранная модель.
- **Gemma** — читает изображение локально; нужны выбранная E2B или E4B и её mmproj. Иностранный текст переводится на русский, русский — на выбранный язык Gemma.

Результат появляется в одной панели. Текст можно выделить и скопировать; нажатие открывает его в компактной карточке с запросами к Gemma. Клик по пустому месту снаружи, Esc или повторный Alt + Q закрывает результат. Скриншоты хранятся в памяти и не отправляются на сервер.

## Подсказки, словарик и оформление

Доступны дополнение слова, исправление опечаток и предложение следующего слова. Их число и показ отдельными элементами или одной строкой настраиваются. При выборе собственного слова и продолжении ввода оно учитывается в личной статистике.

Словарик сохраняет изучаемые русско-английские пары. Для английских слов доступны офлайн-карточки, формы и примеры. Другие языки Gemma пока не сохраняются в этот словарик.

Настраиваются цвета, прозрачность, размер текста, рамки, скругления, анимация и размещение подсказок. Есть готовые стили, сохранение собственных и предпросмотр. При перекрытии каретки доступны скрытие, обтекание и отключение этой проверки.

## Значения по умолчанию

- Argos, английский целевой язык Gemma и Windows OCR для Alt + Q.
- Компактные подсказки, отдельные элементы; «Дополнить» — 4, «Исправить» — 1, «Предложить» — 2.
- Автоматическая выгрузка модели **выключена**. При включении таймера начальное значение — 3 минуты без запросов.
- «Распознавать ошибочную раскладку при переводе» **выключено**.
- Ускорение Gemma на GPU и переключение раскладки правым Alt **выключены**.
- Блокировка Tab в распознанном поле ввода **включена**; поведение при перекрытии каретки — «Обтекает текст».

Это значения новой установки. Сохранённые настройки при обновлении не заменяются.

## Приватность и ограничения

Распознавание и перевод выполняются на компьютере. Интернет нужен для скачивания дополнительных моделей, проверки и загрузки обновлений, а также сетевых функций поддержки проекта. Парольные поля исключены из наблюдения. Личные словарики и настройки сохраняются локально.

Gemma может ошибаться при распознавании мелкого текста, переводе и объяснениях. Проверьте важный результат. Работа с некоторыми игровыми, защищёнными или нестандартными полями ввода может быть ограничена.

Portable использует обфускацию .NET-сборок и нативную компиляцию собственного Python-воркера. Это затрудняет анализ, но не исключает его. Цифровой подписи издателя Windows пока нет.

Ошибки и предложения можно оставить в [Issues](https://github.com/vikaquest/ViTranslate/issues). Предыдущие версии доступны в [Releases](https://github.com/vikaquest/ViTranslate/releases).
